IDotnsRegistry

Git Source

Title: Dot Registry

Minimal on-chain registry for hierarchical name ownership and resolution.

Defines the canonical storage and mutation surface for DotNS nodes. The registry stores explicit owners for non-tokenised nodes (subnodes). For tokenised nodes (base .dot registrations), implementations may use a sentinel owner:

  • records[node].owner == address(0) means "owner is derived from the ERC721 registrar". In that mode, authorisation MUST be based on ERC721 owner/approvals.

Note: security-contact: admin@parity.io
