IStore

Git Source

Title: IStore

Interface defining a key-value storage for IPFS URIs scoped by user address.

Each user maintains an isolated namespace of key-value pairs. Authorized contracts can write on behalf of users.

Permanent locking: Some (user, key) entries can be locked permanently to make them immutable:

  • Locked entries cannot be overwritten by any caller.
  • Locked entries cannot be deleted by any caller, including the store owner.
  • The intended use is for DotNS-related data written by the DotNS registry controller.

Note: security-contact: admin@parity.io

Functions

setValue

Store or update an IPFS URI under a given key for the caller.

Keys are scoped to msg.sender to prevent collisions across users.

Note: reverts: KeyLocked if (msg.sender, key) is locked permanently.

function setValue(bytes32 key, string calldata value) external;

Parameters

NameTypeDescription
keybytes32The unique identifier for the stored value.
valuestringThe IPFS URI to store.

setValueFor

Store or update an IPFS URI under a given key for a specified user.

Only authorized contracts can call this function. Keys are scoped to the specified user.

If the caller is a DotNS controller, the key may be locked permanently as part of the write.

Notes:

  • reverts: NotAuthorised if caller is not an authorized contract.

  • reverts: KeyLocked if (user, key) is locked permanently.

function setValueFor(address user, bytes32 key, string calldata value) external;

Parameters

NameTypeDescription
useraddressThe address whose storage will be modified.
keybytes32The unique identifier for the stored value.
valuestringThe IPFS URI to store.

Only the store owner can authorize new addresses.

Note: reverts: NotAuthorised if caller is not the owner.

NameTypeDescription

authorizeDotnsController

Marks an address as a DotNS controller for locking semantics.

Only the store owner can grant this role. This role does not grant write access by itself; the address must also be authorized via authorizeStore.

Note: reverts: NotAuthorised if caller is not the owner.

function authorizeDotnsController(address controllerAddress) external;

Parameters

NameTypeDescription
controllerAddressaddressThe address to mark as DotNS controller.

unauthorizeDotnsController

Removes DotNS controller status from an address.

Only the store owner can revoke this role. Revoking does not unlock existing locked keys.

Note: reverts: NotAuthorised if caller is not the owner.

function unauthorizeDotnsController(address controllerAddress) external;

Parameters

NameTypeDescription
