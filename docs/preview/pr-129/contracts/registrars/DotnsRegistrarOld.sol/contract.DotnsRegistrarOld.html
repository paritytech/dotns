Title: Dotns Registrar

ERC721-backed registrar implementing permanent name ownership.

This contract is deliberately policy-free. Transfers are supported to allow ownership changes without registry hooks.

Store writes on transfer: When an ERC721 name token is transferred between non-zero addresses (i.e. not mint or burn), the registrar writes the label to the recipient's Store using the label stored in _labels. This ensures the recipient's Store contains a record of every name they have received. Stores are immutable (locked by DotNS controllers), so the sender's entry is not removed.

Note: security-contact: admin@parity.io

_labelhashes

DEPRECATED as of v1.2.0: Previously stored labelhashes per token ID.

Retained for UUPS storage layout compatibility. No longer written to. The labelhash is now derived on-the-fly from _labels[tokenId] via keccak256(bytes(label)). REMOVE this mapping when deploying to a new environment (fresh deploy, not upgrade).

Note: oz-retyped-from: mapping(uint256 => bytes32)

mapping(uint256 tokenId => bytes32 labelhash) private _labelhashes

_labels

Human-readable label per token ID. Single source of truth for name data.

Stored at registration time. Used during transfers to write the label directly to the recipient's Store without needing to read from the sender's Store. The labelhash can always be derived as keccak256(bytes(label)).

mapping(uint256 tokenId => string label) private _labels
