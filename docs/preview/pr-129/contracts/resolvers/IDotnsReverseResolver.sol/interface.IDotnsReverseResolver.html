IDotnsReverseResolver

Git Source

Title: Dotns Reverse Resolver

Interface for writing and reading reverse name records for addresses.

Defines the minimal surface required to associate an address with a human-readable name. Implementations are expected to enforce authorization for writes.

Note: security-contact: admin@parity.io

Functions

setReverseName

Associates an address with a reverse name record.

This function overwrites any existing reverse record for addr.

Note: reverts: NotRegistrar if the caller is not authorised to write.

function setReverseName(address addr, string calldata name) external;

Parameters

NameTypeDescription
addraddressThe address for which the reverse name is being set.
namestringThe human-readable name associated with the address.

nameOf

Returns the reverse name for an address.

Returns an empty string if no reverse name is set.

Parameters

Returns
