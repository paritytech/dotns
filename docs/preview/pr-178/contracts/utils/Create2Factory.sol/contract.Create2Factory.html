Create2Factory

Git Source

Title: Create2Factory

Minimal singleton CREATE2 factory used by the DotNS deploy pipeline to give every protocol contract the same address on every chain.

Determinism rests on three things, all enforced by the deploy pipeline rather than this contract:

  1. The factory itself must live at the same address on every chain. That holds when the same deployer EOA broadcasts the factory constructor as its first transaction (nonce 0) on each chain — address = keccak256(rlp([sender, nonce]))[12:] depends only on the EOA and the nonce, so a fresh deployer hitting nonce 0 lands on the same factory address everywhere.
  2. Every downstream init code is constructor-arg-stable across chains. Implementations have no constructor args so they are trivially identical; ERC1967 proxies take (impl, initData), which is stable as long as impl and every address embedded in initData is itself CREATE2-derived through this factory.
  3. The salt for each contract is fixed per role + version.

Note: security-contact: admin@parity.io

Functions

deploy

Deploys initCode under salt via CREATE2 and returns the resulting address.

The factory itself is the CREATE2 sender, so two callers passing the same (salt, initCode) collide on the same address — which is exactly the point. The second deploy reverts because CREATE2 cannot overwrite existing code.

function deploy(bytes32 salt, bytes memory initCode) external returns (address addr);

Parameters

NameTypeDescription
saltbytes32Caller-chosen salt. Convention is keccak256("dotns:<role>:v<version>").
initCodebytesCreation bytecode plus ABI-encoded constructor args.

Returns

NameTypeDescription
addraddressAddress of the freshly deployed contract.

computeAddress

Precomputes the address deploy(salt, initCode) would yield under this factory. Useful for sanity-checking before broadcast and for cross-chain address verification scripts.

function computeAddress(bytes32 salt, bytes32 initCodeHash) external view returns (address);

Parameters

NameTypeDescription
saltbytes32Salt the caller would pass.
initCodeHashbytes32keccak256(initCode) — caller hashes their own init code so this helper stays calldata-cheap.

Returns

NameTypeDescription
<none>addressThe address the deploy would land at.
